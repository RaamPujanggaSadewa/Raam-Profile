# How I Use AI and Code: Raam Pujangga Sadewa

AI is part of how I work, not a background tool. With a Computer Engineering background, I use it to research faster, write clearer documents, and build what I design.

---

## How I work now

At FLIK, with no dedicated PM, I take merchant features from first request to release:

1. **Requirements**: gathered from Sales, the CEO and merchant feedback.
2. **PRD**: I write it and agree the scope with the team.
3. **Design**: flows and high-fidelity screens.
4. **Build**: in code with Claude Code, on the merchant dashboard (since 2026).
5. **QA and release**: tested in staging and production, then announced to the right merchants (SendGrid).

---

## Where AI helps

### Research
Planning studies and synthesising what users say. I built a tool (Claude Code + Google Apps Script) that turns a research question into a live survey and a findings deck.

### Requirements and documentation
Drafting and structuring PRDs, so specs stay consistent and engineering gets clear briefs.

### Design exploration
Pressure-testing design decisions, surfacing edge cases and exploring alternative flows before committing to one.

### Building
Taking features from design to working code on FLIK's merchant dashboard with Claude Code. My portfolio site is built the same way (Next.js).

### QA
Learning automated testing with Playwright, to understand how QA protects product quality.
